# Description

* %~dp0 — это специальная переменная. Развернем её по символам: 
%0 — это полный путь к текущему скрипту; 
d извлекает букву диска (drive); 
p извлекает путь к папке (path). 
В итоге %~dp0 превращается, например, в C:\MyScripts\.

* PUSHD — переходит в указанную папку и одновременно запоминает предыдущую директорию (сохраняет её в специальный стек), 
чтобы потом можно было вернуться назад.

* Зачем нужна: 
Если запустить bat-файл от имени администратора, Windows по умолчанию изменит рабочую папку на C:\Windows\System32. 
Из-за этого скрипт не сможет найти файлы, которые лежат рядом с ним. Команда PUSHD "%~dp0" гарантирует, 
что скрипт будет работать именно в своей «родной» папке.
